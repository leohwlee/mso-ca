# exam-prep——把任何資料變成溫習筆記及模擬試

[English](README.md) · [下載技能](https://github.com/leohwlee/mso-ca/releases/download/exam-prep-v3.0.0/exam-prep-v3.0.0.zip) · [製作經過](references/case-study.md)

`exam-prep` 是一個 [Agent Skill](https://agentskills.io)：一個載有說明、參考文件、
腳本及範本的資料夾。能讀取 `SKILL.md` 的代理（例如 Claude Code）在有人要求把文件
或文案變成溫習筆記、練習題或模擬試時載入它。它適用於任何科目、任何一種或兩種
語言，以及任何考試形式。

它提煉自本 repo 的發展歷程：為香港金錢服務經營者能力評核製作雙語題庫及溫習筆記，
八個星期內發佈 43 個版本，以及每個版本所需的修正。在五輪對照測試中，同一個模型
使用技能後做出的試卷及筆記明顯較好（36 項檢查通過 34 項，不用技能為 25 項；
詳見[測試結果](#測試結果)）。

## 可以要求它做甚麼

| 你手上有 | 你可以要求 | 你會得到 |
|---|---|---|
| 政策、程序或員工手冊 | 「給新同事做 20 題模擬試，30 分鐘，80% 合格，要離線使用」 | 一個離線 HTML 模擬試（計時試卷、分部分練習、錯題本），及另一份可列印的答案，寫明每題答案及所依據的條文 |
| 任何語言的課本章節或講義 | 「整理溫習筆記，再出 15 道像老師那樣設陷阱的判斷題」 | 按原文章節編排的筆記，標明學習層次，易錯點寫在規則旁；試卷及答案，每條陳述都有解釋及出處 |
| 產品頁、銷售文案或規格表 | 「按我們的格式出認證練習題，再做一頁速查表」 | 完全照你給的選項格式出題；速查表列出每項條件及例外；另列出文案未能支持的說法 |
| 法例、指引、專業考試範圍 | 「為整個考試建題庫，按真實合格規則抽題」 | 有版本管理的數百題題庫、按部分抽題的試卷、盲審、覆蓋率審核及分部分筆記 |
| 現有題庫 | 「檢查這些題目有沒有露底」 | 硬性錯誤、表面線索報告（含自學猜題器及模擬試卷）、盲審題包 |

題型：單選、多選、組合題（K 型）、是非題、配對、排序、填充、數值題、
附評分準則的短答及論述題，以及個案題組。可匯出 QTI、Moodle XML、GIFT、
Aiken 或 Anki。

**不適用於**：需要保密或監考的正式考試（離線應用程式把答案放在網頁內）；
沒有文字層的掃描文件（請先做文字辨識）；以及沒有評分準則可以描述的作品評核。

## 它有甚麼不同

- **每題都有根據。** 每題附有可翻查的出處及決定答案的原文；內置檢查會在抽取出的
  原文中逐字找出每段引文。
- **陷阱考閱讀，不考運氣。** 每條錯誤陳述只有一處小改動，而且屬於有名稱的類型：
  改動程度詞（「主要」→「只」）、換成相鄰的數字、換錯負責人、漏掉條件。換入
  無關術語這種人人都能排除的做法不被採用。
- **以應試技巧作對照測量。** 線索報告會計算「選最長」「選和其他選項最相似」及
  以題庫自身訓練的猜題器的命中率，再按真實合格規則模擬試卷。組合題選項按對稱
  方式生成，結構不會洩露答案。
- **能找出審題人容易漏看的問題**，例如：
  - 答案照抄原文而干擾項都經改寫；
  - 正確陳述只是原文刪減拼接；
  - 一題的正確陳述洩露另一題的錯誤陳述；
  - 筆記寫出了錯誤陳述的說法；
  - 解釋提到「選項 B」，選項一打亂就錯。
- **筆記從原文寫，不從題目抄。** 按原文結構編排；易錯點寫在所保護的規則旁；
  清單標明項數；限定詞原樣保留；設學習層次篩選及默記模式。
- **先定好真實考試形式。** 完全照印好的選項格式出題，推算這種格式會讓考生推斷出
  甚麼，並按真實的分部分規則抽題。
- **按規模投入。** 十題的要求走快速路徑；整個題庫則有獨立覆核、版本管理及審核。
- **附離線模擬試應用程式。** 功能包括：
  - 計時模擬試及答題紙；
  - 分部分練習；
  - 錯題本；
  - 文字答案自行評分；
  - 匯出紀錄；
  - 畫面上顯示題目編號，與列印的答案對應。

## 測試結果

三個實際要求，各由同一個模型（Claude Opus 5.5）在使用及不使用技能的情況下完成，
再由另一個評分代理按書面檢查項目逐項評分：
- 把英文資訊保安政策做成 20 題離線模擬試；
- 把簡體中文生物講義做成筆記、15 道判斷題及 3 道簡答題；
- 把產品文案做成 10 道組合題及速查表。

每一輪之後檢查項目都會收緊，所以後面的輪次更難。

| 輪次 | 使用技能 | 不使用 | 與上一輪相比，技能的改動 |
|---|---|---|---|
| 1 | 24/24 | 24/24 | 第一版；檢查太寬，分不出高下 |
| 2 | 31/31 | 27/31 | 小任務的快速路徑、能騙倒一知半解者的陷阱、改寫正確陳述、筆記不抄題目 |
| 3 | 31/35 | 26/35 | 檢查一題洩露另一題、情景題、成績回顧及答案顯示題目編號、限時自動交卷檢查 |
| 4 | 34/36 | 26/36 | 檢查照抄的答案、照抄的正確陳述及洩露錯誤陳述的筆記；程度詞陷阱 |
| 5 | 34/36 | 25/36 | 更嚴格的照抄規則、兩種語言的筆記洩露檢查、保護簡答題不被判斷題洩露 |

第五輪各要求的結果：

| 要求 | 使用技能 | 不使用 | Token（使用／不使用） | 時間（使用／不使用） |
|---|---|---|---|---|
| 政策 → 離線模擬試 | 11/11 | 10/11 | 23 萬／18 萬 | 18／16 分鐘 |
| 中文講義 → 筆記及判斷題 | 12/13 | 9/13 | 28.6 萬／11.6 萬 | 28／9 分鐘 |
| 產品文案 → 組合題 | 11/12 | 6/12 | 29.2 萬／12 萬 | 43／8 分鐘 |

第五輪不使用技能時出現的問題：
- **政策模擬試**：六道題的答案逐字照抄政策，干擾項卻是改寫過的。
- **中文筆記**：
  - 把講義的「主要」寫成「只」；
  - 把八條錯誤陳述的錯誤說法全部寫了出來；
  - 正確陳述照抄講義；
  - 有幾道判斷題洩露了簡答題的得分點。
- **產品題**：
  - 沒有一道題以客戶情景開題；
  - 至少十條陳述照抄產品頁；
  - 一題洩露另一題（「水箱容量 4 升」與「1.2 升」並列）；
  - 解釋沒有說出依據產品頁哪一節；
  - 有兩條陳述考的是文案本身而不是產品。

使用技能仍然遺漏的地方：
- **中文講義**：一道正確陳述保留了講義原句的結構，只換了近義詞。
- **產品題**：說明了用戶給的選項格式每題最多一條錯誤陳述，卻沒有指出考生因此找到一條錯的就可以停下。

兩者現已有明確指引，但尚未重新測量。

**成本。** 使用技能時，每次運行的 token 用量是不使用時的 1.3 至 2.5 倍，時間也
較長。多出的部分幾乎全是模型針對各項檢查的推理，而不是讀檔。

**這些數字的局限。**
- 每種設定每輪只運行一次，由模型評分。
- 使用技能時的自我盲答只是自查，不是獨立覆核。
- 不使用技能的產出只製作一次，之後每輪重新評分。

測試個案放在 [`evals/`](evals/)，格式符合 `claude plugin eval`，任何人都可以重跑。

## 安裝

下載 [exam-prep-v3.0.0.zip](https://github.com/leohwlee/mso-ca/releases/download/exam-prep-v3.0.0/exam-prep-v3.0.0.zip)。
壓縮檔內只有一個資料夾 `exam-prep/`。使用 Claude Code 時，解壓到以下其中一處：
- `~/.claude/skills/`：所有項目適用；
- `<項目>/.claude/skills/`：只限單一項目。

無論哪一處，`SKILL.md` 都應位於 `.../skills/exam-prep/SKILL.md`。

然後直接提出要求，例如：「把這些 PDF 做成溫習筆記和一份 40 題的模擬試」。

腳本只需 Python 3.9 或以上；如已安裝 PyMuPDF 或 pypdf，會用來抽取 PDF 文字。

## 試用示例

```bash
python scripts/selftest.py
python scripts/bank_tool.py check assets/example/spec.json assets/example/bank.json --sources assets/example/sources
python scripts/build_app.py assets/example/spec.json assets/example/bank.json -o example-exam.html
```

把 `assets/notes-template.html` 複製到 `example-exam.html` 旁並命名為 `notes.html`，
應用程式的「在筆記中閱讀」連結即可使用。
