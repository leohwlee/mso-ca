# 使用指南

[English](USAGE.md) · [專案首頁](../README.zh-Hant.md) · [文件索引](INDEX.md)

## 下載及開啟

如需七部分筆記及練習，在[最新發佈版](https://github.com/leohwlee/mso-ca/releases/latest)
選 **mso-study-bundle.zip**，完整解壓後開啟 `index.html`。保留資料夾結構：
內含練習App和引用的01–26原件，App中的溫習連結亦須配合此學習包。

在[最新發佈版](https://github.com/leohwlee/mso-ca/releases/latest)下載 **mso-ca.html**。
請選擇這個附件，而非GitHub的原始碼ZIP，再用瀏覽器開啟下載的檔案。
程式所需內容已全部內嵌；閱讀官方來源原件則是另一項活動。

以語言按鈕選擇英文、繁體中文或中英並列。使用期間可切換語言及明暗主題。

## 模擬試

按**開始模擬試**。每份試卷有35題，七部分各5題，總時限75分鐘。
選擇列出所有正確陳述的組合選項，可前後移動及標記稍後重看的題目。
完成後交卷；時限屆滿也會結束試卷。關閉分頁不會暫停截止時間。

須同時答對至少25題，且**每部分至少答對3題**才及格。未作答視為錯誤。
結果頁提供原有成績、各部分表現、逐句解析及來源。

同一瀏覽器儲存空間內的有效未完成試卷可以繼續。如果題庫更新移除了其中一道題目，
程式會要求重新開一份完整試卷，以免繼續一份不足35題的試卷。

## 自選練習

在首頁選擇一個或多個 **Part 1–7** 按鈕，或按**全選**。至少保留一個部分。
按**開始練習**後，只會從選定範圍抽題，不設時限。每次作答後可查看各項陳述的判斷及解析，
再移至下一題。題目隨機排列，完成所選範圍一輪後會再開始下一輪。

同一道題在另一次作答時，陳述次序可能不同。應記住規則及適用條件，而不是選項字母或陳述編號。

## 備份及還原成績

1. 在首頁展開**模擬試成績及紀錄**。
2. 按**儲存紀錄至檔案 (.md)**，保管好下載的檔案。
3. 在新瀏覽器或新版本按**從檔案載入紀錄**，選取該備份。

備份同時包含可閱讀的成績及程式匯入所需資料，但不會備份未完成試卷。
自選練習不會產生已完成的模擬試紀錄。

不同檔案位置、瀏覽器及裝置可能使用不同儲存空間。私密瀏覽或清除瀏覽器資料可能使紀錄消失。
請在升級或移動HTML檔案前匯出紀錄。歷史成績會按原樣保留；
若舊題已從現行題庫移除，可能無法再查看該題的解析。

## 理解來源及題意

程式只使用01–26的本地文件。答案附有來源定位（條文、段落或頁碼）及逐句解析。
實際版本見[閱讀目錄](README.zh-Hant.md)，題庫範圍見[來源對照](QUESTION-SOURCES.zh-Hant.md)。

第24份沒有官方中文版本，相關中文練習內容標明學習譯文。
第25份所引結論歸屬2022年報告。另行提供的歷史溫習資料採用較舊範圍，
不是525題現行題庫的準據。

## 常見問題

| 問題 | 處理方法 |
|---|---|
| 看到程式碼或GitHub檔案列表 | 下載發佈附件 `mso-ca.html`，再用瀏覽器開啟本地檔案。 |
| 直接開 `web/index.html` 無法載入題目 | 使用發佈版HTML；開發者可依開發說明啟動本地伺服器。 |
| 題數仍是舊版本 | 重新下載最新版本；本地HTML不會自動更新。 |
| 升級後成績不見了 | 載入事先匯出的紀錄；新的位置或瀏覽器可能使用不同儲存空間。 |
| 總分很高仍不及格 | 查看各部分錯題數；任何一部分錯3題便不及格。 |
| 題意似乎有歧義 | 核對引用的本地版本及解析。反映問題時提供題號、語言及相關原文，勿附私人客戶資料。 |

建立及維護程式請參閱[開發說明](../DEVELOPMENT.zh-Hant.md)。
