# MSO 精簡閱讀目錄

[English →](README.md)

日常閱讀共 **26項材料，連續編號01–26**，配套文件也各佔一個編號。全部原件直接放在[中文資料夾](TC/)及[英文資料夾](EN/)，每個資料夾26份。兩部雙語法例在兩個資料夾各放一份。

按檔名排序，就是「01–09高優先級 → 10–19中重點 → 20–26中選讀」。不留空號，也沒有另一套來源ID。第16項通函後接第17項完整第34章；第22項通函後接第23項完整第629章。歷史參考材料接續編為27–47，放在archive內。

**最先掌握03、04、05**：反洗錢指引、第615章及牌照指引。01、02先快速了解考試及試題；06至09用來補足實際應用和明確監管要求。完成高優先級後，先讀「中重點」，再按薄弱範圍讀「中選讀」。

依據：[官方《能力評核須知》第5.2至6.1段](https://eservices.customs.gov.hk/MSOS/download/licensing/Guidance_Notes_on_the_Competence_Assessment_for_Money_Service_Operators_zh_TW.pdf)。七個單元涵蓋法例、核心指引、其他指引及通函；以下是復習建議，並非官方出題權重。

從47項收錄材料中移出21項：完整法例已覆蓋的摘錄、舊期通知、重複培訓、歷史決議及較遠離核心範圍的材料，見[移出清單及原因](archive/README.zh-Hant.md)。原件及題庫證據仍保留；移出不代表失效或不會考，現行題庫只用01–26，這些材料只供歷史參考。

v1.12.0的[七部分溫習筆記](../revision/study-notes/index.html)保留高優先級原文的清單、條件及例外；[覆核範圍與限制](../revision/study-notes/README.md)另列。離線閱讀請從[版本頁](https://github.com/leohwlee/mso-ca/releases/tag/v1.12.0)下載完整學習包。這次沒有更新來源版次或擴大01–26範圍。
