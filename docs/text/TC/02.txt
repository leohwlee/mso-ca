例子 (2) 
有關金錢服務經營者持牌人經營金錢服務的情況，下列哪項正確？ 
 
1. 持牌人須在指明的處所內的一處顯眼地方，展示該牌照的正本或複本。 
2. （如該處所屬住宅處所）申請人須確保取得該處所的每名佔用人的書面同
意，讓獲授權人為行使第615 章《打擊洗錢及恐怖分子資金籌集條例》（打
擊洗錢條例）所授予的權力而進入該處所。 
3. 如在與持牌人提出的牌照申請或牌照續期申請有關連情況下提供予關長
的詳情有改變，該持牌人須在自改變發生之日起計的一個月內，藉書面向
關長具報有關改變。 
4. 持牌人如擬停止經營金錢服務，須在停業日期前藉書面向海關關長具報該
意向。

例子 (3) 
關於金錢服務經營者持牌人的法定客戶盡職審查規定，下列哪項正確？ 
 
1. 識別客户的身分，及根據政府機構所提供的文件、數據或資料，核實該客户
的身分。 
2. 金錢服務經營者不得開立或維持匿名戶口。 
3. 金錢服務經營者須藉對為客戶執行的交易進行適當的審查，以確保它們符
合其對客戶、客戶的業務及風險狀況的認知，以持續監察與客戶的業務關
係。 
4. 金錢服務經營者在進行涉及相等於$8,000或以上的款額的匯款交易前，須藉
參考匯款人的識別文件，核實匯款人的身分。

例子 (4) 
關於金錢服務經營者持牌人的本地管理辦事處的規定，下列哪項正確？ 
 
1. 無論持牌人會或不會在特定處所經營金錢服務，都須維持本地管理辦事處。 
2. 本地管理辦事處須駐有持牌人的合規主任、獨資經營者、合夥人、董事或最
終擁有人。 
3. 本地管理辦事處可讓海關人員親身前往及以電話聯絡。 
4. 如金錢服務經營者持牌人未能維持本地管理辦事處，將可能會導致暫時吊
銷及撤銷金錢服務經營者牌照。
