# Authoring guide for the MSO revision pack

Paths below are relative to `revision/`. See `README.md` for building and checking.

## What the pack is
A bilingual (English / Traditional Chinese) single-file HTML revision pack for the Hong Kong C&ED
**Money Service Operator (MSO) Competence Assessment**: 35 multiple-choice questions, seven modules of five
((1) general AML/CFT and counter proliferation financing knowledge; (2) AMLO Parts 1–7; (3) AMLO Schedules;
(4) C&ED guidelines; (5) systems and controls: institutional governance and strategy; (6) AML/CFT control
areas; (7) demonstrating and monitoring compliance). Pass = no more than 2 wrong in any module AND ≥25/35.
The reader is an MSO owner memorising for a closed-book exam. They read in three modes: English only,
Chinese only, or both.

Pages are generated by Python modules in this folder (one module per page, plus figure modules) and
assembled by `pack_build.py`. Look at `gl.py` + `gl_fig.py` (the Guidelines page) and `s2x.py` as models.
`review/extract.py` writes the current text of every page, section by section, to `review/sections/*.txt`
(EN VIEW and TC VIEW). Grep those before writing so you never repeat what another page already says —
link to it instead (`<a href="#s2-monitoring">Schedule 2 page</a>`).

## The reader's rules (from the owner's own feedback — follow them exactly)
- **Situation first.** Headings and card titles state the situation or the plain rule. Never make a section
  or paragraph number the subject of a heading ("¶7.13 says…" is wrong; "Staff reports go straight to the
  MLRO, unfiltered" is right). Citations trail as support.
- **Format hierarchy:** a process or interaction → a **flowchart**; rules that change with the situation →
  a **table whose rows are the scenarios**; key numbers and deadlines → a **number table** (`numreq`:
  the number | what it requires | when it applies | if it is missed); **bullet points only as a last resort**
  (the checker flags `<li>`). Every page should visualise its key content (at least one figure per page,
  more where there is a process).
- **Highlight what is easy to confuse** with `trap(...)` callouts ("Easy to confuse") and `flag()` markers
  inside table cells. Prefer `vs=[...]` side-by-side contrasts.
- **Colour must carry a stated meaning and be keyed.** Every figure that uses node colours gets a
  `legend([...])` passed to `fig(...)`. Kinds: `must` (red: a duty/deadline/consequence for you),
  `may` (amber: a power or discretion someone else holds), `ok` (green: a safe outcome/protection),
  `stop` (black: an end state such as refusal, offence), `faint` (dashed: background/context),
  `''` (plain grey: a neutral step), `hex` (a question node, `Node(..., shape='hex')`).
- **No section-by-section listings, no "who is who" filler, no drill/quiz sections, no standalone
  "numbers" section** — numbers live in the section they arise in.
- **Don't repeat the page overview** in the paragraph above the first diagram; that paragraph says how to
  read the diagram.
- **Chinese view contains only Chinese; English view only English.** Bilingual appears only in the combined
  view. Every text is an (en, tc) pair.
- **Each language view follows its own source text.** Where the English and Chinese texts of a document
  differ (may / 將, or / 及, should / 必須), the English view says what the English text says and the Chinese
  view what the Chinese text says. Never compare the two versions on the page. A point that exists in one
  language's text only can be shown in that view only, with the `only-en` / `only-tc` classes.

## Accuracy — the non-negotiable part
Every sentence must be grounded in a source passage, and every table cell, card and callout carries a
citation to the paragraph/section that supports it. Sources: the 23 current documents in `../docs/EN` and
`../docs/TC` (listed in `../docs/README.md`; 02 = AML/CFT Guideline for MSOs, June 2023; 10 = AMLO Cap. 615).
Extract their text first (e.g. `pdftotext -layout`) and search it for distinctive phrases.
- Paraphrase faithfully; keep conditions, qualifiers and modal strength (must / should / may).
- Never invent examples, numbers or lists and present them as the source's. If you illustrate, say so.
- Chinese must use the **official Chinese terms of the Chinese source** it cites (docs/TC/02, docs/TC/10):
  e.g. 可疑交易報告, 聯合財富情報組 (short form 財富情報組), 洗錢報告主任, 合規主任, 通風報訊,
  客戶盡職審查, 更嚴格的客戶盡職審查措施, 政治人物, 實益擁有人, 風險為本的方法, 機構層面的風險評估,
  針對性金融制裁, 擴散資金籌集, 指定各方 / 被指認各方 (as the paragraph says), 恐怖分子財產, 批給, 會面, 應考能力評核,
  數據庫, 複本, 證明人, 覆核, 職員, 打擊洗錢／恐怖分子資金籌集制度. Check each term in the source before use.
- If two documents conflict, teach the side the owner chose (`CONFLICT-CALLS.md`); for a conflict not listed
  there, say so neutrally and ask the owner rather than picking one silently.

## Citations
- AML/CFT Guideline paragraph: `"¶7.13"` (auto-converted to 第7.13段 in Chinese). Several: `"¶7.13–7.14"`,
  `"¶2.4(d)"`. Chapter: `"Ch. 7"`.
- AMLO section: `"s.25A"`; Schedule 2 section: `"s.13 Sch. 2"`. Other ordinances need an explicit pair:
  `("DTROP s.25A(1)", "《販毒（追討得益）條例》第25A(1)條")`, `("OSCO s.25", "《有組織及嚴重罪行條例》第25條")`,
  `("UNATMO s.12", "《聯合國（反恐怖主義措施）條例》第12條")`, `("UNSO", "《聯合國制裁條例》")`,
  `("WMD(CPS)O s.4", "《大規模毀滅武器（提供服務的管制）條例》第4條")` — take the exact names from docs/TC/02.
- Join several with `cc(a, b)` (define it as in gl.py) or write `"¶7.13 · s.25A"`.
- Tuple citations `(en, tc)` must contain no Latin words in the Chinese half.

## API (import with `from ui import *`; see ui.py and bl_core.py)
- `sec(id, margin_list, (h2_en, h2_tc), body_html)` — one section. `margin_list` items are citation strings
  or (en, tc) pairs (short). Section ids must be unique within your page; they become `<pagekey>-<id>`.
- `P(en, tc)` paragraph; `h3(en, tc)`; `B(en, tc)` inline pair; HTML inside strings is allowed
  (`<b>`, links). Escape `&` as `&amp;` in HTML text (not inside citations or figure text).
- `table([th(en,tc), ...], [tr(rh(en,tc,cite), td(en,tc,cite, post=flag()), ...), ...], note=..., minw=720, cls='')`
  — `cls='cmp'` gives fixed equal columns for side-by-side comparisons. `td(..., cls='pen')` blurs in
  recall mode (use for penalties/numbers).
- `numreq([ ((num_en,num_tc), (req_en,req_tc), (when_en,when_tc), (miss_en,miss_tc), cite), ... ], heading=True)`
- `trap((title_en,title_tc), (body_en,body_tc) or None, cite, vs=[((lab_en,lab_tc),(txt_en,txt_tc)), ...])`,
  wrapped in `traps(trap(...), trap(...))`.
- `chip(en, tc, 'ink')`, `YES`, `NO` for verdict cells (`f'<td class="verdict">{YES}</td>'`).
- Figures: write `def fig_x():` returning `svg(W, H, body, (aria_en, aria_tc), 'uniqueMarkerId', minw)` and
  place it with `fig(fig_x, (caption_en, caption_tc), legend([...]))` — **pass the function, not its result**:
  the pack draws each figure three times, once laid out per language view.
  Building blocks: `Card(x, w, (title_en,title_tc), (body_en,body_tc) or None, kind, cite, href=None, minh=0, answer=False)`
  (bold title + body; preferred), `Node(x, w, (en,tc), cite, kind, shape='hex')` (a question), 
  `place([([n1, n2], gap_after), ([n3], gap), ...], y0=14)` sets y and returns height;
  `edge([p1, p2, ...], (lab_en,lab_tc), lx, ly, anchor, mid='uniqueMarkerId')` with points like
  `n.bottom`, `n.top`, `n.left`, `n.right`, `(x, y)`; `mlabel(x, y, en, tc)` for an edge label;
  `lines_down(cx, y_top, [en lines], [tc lines], 'c-sans', size)` from `bl_figs` for free text.
  Use a marker id unique in the whole pack (prefix it with your page key, e.g. 'g7a').
  Figures are ~1000 units wide (min-width 860) and display ~870px wide. Sizes you pass are multiplied by
  FS=1.25 automatically; keep the defaults (Card 11.5/12.5, Node 12) or larger — never smaller than 10.5.
  Keep connectors from crossing text or boxes; put yes/no labels right beside their branch; give every
  arrow an obvious start and end; do not reuse the same x for unrelated arrows.
- `answer=True` on outcome boxes lets recall mode blur them.

## Module contract
Write `<key>.py` (and optionally `<key>_fig.py`). It must define:
- `<KEY>_BODY` — the concatenated sections (string), `<KEY>_NAV` — `[(section_id, en_label, tc_label), ...]`
  in page order (labels 1–4 words), and
- `<KEY>_META = dict(tab=("1","1"), short=(en, tc), eyebrow=(en, tc), title=(en, tc), lede=(en, tc), foot=(en, tc))`
  — `short` is the outline heading (e.g. ("Guideline Ch. 7 · STR", "指引第7章 · 可疑交易報告")); `eyebrow` like
  ("AML/CFT Guideline · Chapter 7 · Module 6", "《打擊洗錢指引》第7章 · 單元六"); `title` a short name;
  `lede` 2–4 sentences on what the chapter decides for the reader (not a list of sections); `foot` names
  the exact sources drawn on. No `&` in `short`/`tab`.

## Check your work (mandatory loop)
Build the pack first (`python pack_build.py`), then run:
`cd revision && PYTHONIOENCODING=utf-8 python review/page_check.py <key> <KEY>_BODY <KEY>_NAV <key>`
It prints problems (language purity, dead links, figures not drawn per view, bullets, duplicate ids) and
renders every figure to `review/preview/<key>_figN_{en,tc,both}.png`. Open every PNG with the Read tool
and look hard: overlapping or clipped text, labels far from lines, arrows crossing boxes/text, cramped or
half-empty boxes, small text. Fix and re-run until the checker is clean and the figures look right.
Also re-read your text against the sources once more at the end.
