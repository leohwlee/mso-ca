# 金錢服務經營者能力評核 — 模擬試

[English](README.md) · [下載 App](https://github.com/leohwlee/mso-ca/releases/latest/download/mso-ca.html) · [版本更新](CHANGELOG.md)

**525 道英文／繁體中文組合題**，出題依據只限[閱讀文檔庫](docs/README.zh-Hant.md)
的 **01–26**。可離線準備香港金錢服務經營者能力評核，只有**模擬試**與**自選練習**兩個模式。

## 三步開始

1. 從最新發佈版下載 **[mso-ca.html](https://github.com/leohwlee/mso-ca/releases/latest/download/mso-ca.html)**。
2. 用瀏覽器開啟下載的檔案，無須安裝、登入或啟動伺服器。
3. 選擇 **EN**、**中文**或 **EN+中**，再開始模擬試或選擇練習部分。

HTML 檔案已包含程式、題庫及字型。使用時無須下載整個專案或安裝 Go；
官方參考原件另見閱讀文檔庫。

![525題題庫及兩個模式的首頁](docs/images/app-preview.png)

## 選擇練習方式

| 模式 | 使用方式 |
|---|---|
| **模擬試** | 隨機抽出35題，七部分各5題，限時75分鐘。交卷後查看成績、解析及出處。 |
| **自選練習** | 選擇Part 1–7中的一個或多個部分，不設時限，作答後立即查看解析。 |

模擬試須同時達到**總分至少25/35、每部分錯題不多於2題**才算及格。
即使取得32/35，若三道錯題全在同一部分，仍不及格。
練習題庫中題數較多的部分，不會在模擬試獲分配更多題目。

每題包含4至6項陳述及5個組合選項。每次抽題會重排陳述，選項同步對應。
干擾項測試條件、責任人、期限、門檻及例外；每項陳述均有獨立解析。

## 保存成績

展開**模擬試成績及紀錄**，即可重溫已完成試卷，或匯出可閱讀的 `.md` 備份。
紀錄儲存在瀏覽器，不會自動跨裝置同步。
**更換版本、移動檔案、更換瀏覽器或清除瀏覽器資料前，請先匯出紀錄**，再於新檔案載入。
若未完成試卷包含已退役題目，須重新開卷；已完成試卷的原有成績會保留。
