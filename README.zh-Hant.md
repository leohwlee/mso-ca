# 金錢服務經營者能力評核 — 溫習與練習

[English](README.md) · [下載完整學習包](https://github.com/leohwlee/mso-ca/releases/latest/download/mso-study-bundle.zip) · [版本更新](CHANGELOG.md) · [exam-prep 技能](skills/exam-prep/README.zh-Hant.md)

**七部分溫習筆記及563道組合題**，用於準備香港金錢服務經營者能力評核。
筆記及練習均可離線使用，提供繁體中文、英文及雙語。選定來源為
[閱讀文檔庫](docs/README.zh-Hant.md)的 **01–24及26**；練習分為**模擬試**與**自選練習**兩個模式。

## 開始使用

1. 從最新發佈版下載 **[mso-study-bundle.zip](https://github.com/leohwlee/mso-ca/releases/latest/download/mso-study-bundle.zip)**。
2. 完整解壓後，用瀏覽器開啟 `index.html`，無須安裝、登入或啟動伺服器。
3. 選擇閱讀七部分筆記或練習。練習時選擇 **EN**、**中文**或 **EN+中**，再開始模擬試或選擇練習部分。

學習包內含七部分筆記、練習App及引用的01–24及26原件；保留資料夾結構，
閱讀、練習和來源連結才可離線互通。使用時無須下載整個專案或安裝 Go。

## v1.14.3 更新

溫習筆記版本：正文中的法例代號及可分辨條次，可在電腦懸停或在手機點按，查看官方簡稱、一句白話說明，以及「這是學習提示，不是法例原文」的註明。連到原文PDF或附錄的出處連結（`<a>`、`.citations`、`.source-citation`、`.visual-links`）維持普通連結，不加這種效果。第25條按上下文分辨：AMLO 第25條是發牌豁免；DTROP／OSCO 第25條是處理犯罪得益。

本工作副本的筆記仍包括七部分**白話改寫**並附**例子**、**刪去同一小節內的重複**，以及第2部分及**數字總表**的 **《刑事訴訟程序條例》（第221章）附表8** 六級罰款對照（港幣2,000／5,000／10,000／25,000／50,000／100,000元）。那些筆記修訂已隨 v1.14.2 發出。第221章不在01–24及26指定文本內，那些文本通常只寫「第n級罰款」；表列只引用准許來源中的該等行文。金額本身來自第221章附表8，不是那些《打擊洗錢條例》／第34章／第629章條文寫出的數字。572道題及其答案與解析、評分、題庫範圍（**01–24及26**；第25份仍退役）及練習App均與v1.14.2相同。

## 選擇練習方式

| 模式 | 使用方式 |
|---|---|
| **模擬試** | 隨機抽出35題，七部分各5題，限時75分鐘。交卷後查看成績、解析及出處。 |
| **自選練習** | 選擇Part 1–7中的一個或多個部分，不設時限，作答後立即查看解析。 |

模擬試須同時達到**總分至少25/35、每部分錯題不多於2題**才算及格。
即使取得32/35，若三道錯題全在同一部分，仍不及格。
練習題庫中題數較多的部分，不會在模擬試獲分配更多題目。

每題包含4至6項陳述及5個組合選項。每次抽題會重排陳述，選項同步對應。
干擾項測試條件、責任人、期限、門檻及例外；每項陳述均有獨立解析。

## 自己製作：exam-prep 技能

本題庫背後的方法已整理成通用的 Agent Skill **[exam-prep](skills/exam-prep/README.zh-Hant.md)**。
把任何文件或文案交給編程代理，它就會做出溫習筆記、練習題或離線模擬試，不限科目、
語言及考試形式。例如：
- 把政策做成入職測驗；
- 把課本章節做成筆記及判斷題；
- 把產品文案做成認證練習題。

同一個模型在使用及不使用技能的情況下，就三個這類要求做了對照測試，檢查項目
經五輪逐步收緊：

| 要求 | 使用技能 | 不使用 |
|---|---|---|
| 政策 → 離線模擬試 | 11/11 | 10/11 |
| 中文講義 → 筆記及判斷題 | 12/13 | 9/13 |
| 產品文案 → 組合題 | 11/12 | 6/12 |

不使用技能時，同一個模型：
- 把原文照抄成答案；
- 讓一題洩露另一題；
- 筆記把「主要」寫成「只」；
- 筆記寫出每一條錯誤陳述。

[技能頁面](skills/exam-prep/README.zh-Hant.md)載有適用情境、與別不同之處、完整測試結果及成本。
下載：[exam-prep-v3.0.0.zip](https://github.com/leohwlee/mso-ca/releases/download/exam-prep-v3.0.0/exam-prep-v3.0.0.zip)。
