# 金錢服務經營者能力評核 — 溫習資料及模擬試

[English version →](README.md)

## 這是甚麼

為香港海關「金錢服務經營者能力評核」而設的免費溫習材料——持牌人的獨資經營者、合夥人或董事必須通過的考試。材料分為兩個 HTML 檔案：溫習資料及模擬試，全部只根據官方文件撰寫。兩者各為單一檔案，可離線使用，並可選英文、繁體中文或中英並列。毋須安裝，亦毋須開設帳戶。

## 如何使用

1. 在[最新版本](../../releases/latest)下載 `mso-revision-pack.html` 及 `mso-ca.html`。
2. 用 Chrome 開啟；Edge 及 Firefox 亦可。
3. 先在溫習資料讀一個課題，再到模擬試的「練習」操練該單元——每答一題即顯示解釋及出處。
4. 做完整的計時模擬試，再用「練習答錯的題目」重做錯題。臨近應考時勾選「試場模式」，試卷會全部採用海關的組合題格式。

及格須**每個單元錯題不多於 2 題，及總分達 25/35 或以上**；即使總分很高，只要一個單元失手即屬不及格。

成績只留在你的瀏覽器。請每次開啟同一個 `mso-ca.html`，並用「儲存紀錄至檔案」備份，或帶到另一部電腦。如想做短時間練習，可在網址列的 `mso-ca.html` 後加上 `?minutes=20`。

如要從原始碼建置或發佈新版本，見 [DEVELOPMENT.zh-Hant.md](DEVELOPMENT.zh-Hant.md)。
